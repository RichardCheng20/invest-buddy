# 投研框架（EXAMPLE）

> 规则门槛以 `config/signal_rules.yaml` 为准。本页说明这些数字是干什么的。输出只供对照，不是下单指令。

## 限额

| 规则 | 默认 |
|---|---|
| 总敞口 | ≤ 100%，现金不为负 |
| 单只股票 | ≤ 净值 10%（期权按 delta 计入同一标的） |
| 单一主题 | ≤ 净值 25% |
| 短线单笔 | 最多亏净值的 0.5% |
| 中线单笔 | 最多亏净值的 1% |
| 全部持仓到止损 | ≤ 净值的 4% |

去杠杆计划在总览和决策页。规则给出卖出的仓位可以整仓退出；其余仓位只减到限额，不减到零。计划做完后，杠杆、现金、单票和主题都要落在上限以内。

## 止损

持仓详情可以填写成本、止损和建仓日期，写入 `data/portfolio.yaml`。建议止损取吊灯和「50 日均线减若干倍 ATR」里仍低于现价、且更接近现价的那个。填好后到券商挂出同样的价格。

## 财报

财报风险用平值跨式和近 8 次跳空。跨式取不到就留空，不用一个固定百分比填上。规则清单在没有报价时仍按 `implied_move_fallback`（默认 15%）做核对，页面会标明这是近似。

## 研究

定时调用你配置的 OpenAI 兼容模型，把结果写入 `data/research`。详情里的「立即研究」只跑当前这一只。股数和动作始终以规则引擎为准。
